# kuku2api v1.0.1

发布日期：2026-10-13。

## 修复

- Chat Completions 的 `content` 文本块数组正确按顺序拼接，保留原有文本与换行，不再把多个文本块转换为 `[object Object]`。
- 发送上游前校验文本、工具及附件能力。未实现的客户端工具调用、工具结果、图片和文件等明确返回 HTTP 400；混合内容整体拒绝，不静默丢弃后继续生成。
- Responses 同步拒绝不支持的输入项与内容块，不再过滤工具结果后重发较早的用户消息。
- 保持上游等待客户端时的安全失败行为，不自动换号重发已发送的对话。

## 兼容范围

此版本适用于纯文本对话，不提供完整的 OpenCode 工具执行协议。OpenCode 用户应禁用工具、MCP 和附件，并开启新对话；需要读写代码、执行命令的编程 Agent 仍需支持工具调用的服务。仅切换模型或思考档位不能补齐协议。

Chat 多轮仍需每个聊天独立的 `x-kuku-session` 并固定账号；Responses 使用 `previous_response_id`。当前桥接只发送最新用户输入，不会完整重放客户端的历史或替换上游系统指令。详见 [使用说明](../usage.md#opencode-等编程客户端) 与 [API 文档](../api.md#chat-completions)。

## 安装与升级

使用 [一键安装/升级](../../README.md#快速安装)，或下载 [v1.0.1 预编译安装包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.0.1)。服务器无需构建前端。保留账号、API 密钥、管理员令牌、端口和既有保留策略；新安装日志默认保留 7 天。

## 验证

新增 27 项消息兼容性回归，涵盖流式/非流式文本数组、工具及附件的发送前拦截、Responses 输入及上游等待状态不自动重试。发布流程同时执行 Linux、Windows 后端回归和预编译安装检查。
