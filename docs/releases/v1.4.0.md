# kuku2api v1.4.0

发布日期：2026-11-12。

## 新增功能

- 号池管理 → 新增账号弹窗改为「先选平台」的两级导航：百度账号（App 扫码 / 手机验证码）与超算互联网（验证码登录 / 账密登录）；移除无实际用途的「手动录入凭据」入口。
- 新增超算互联网（SCNet）账号分类，支持两种加号方式：手机号短信验证码，或用户名 + 密码登录。密码仅在服务端 RSA 加密后发往超算，提交后立即清除输入框、不写入浏览器本地存储；登录后自动获取免费活动密钥，如触发图形验证码按提示完成校验即可。
- 反代平台自有免费模型 `SCNet-Max`：在 Chat Completions 与 Responses 中将 `model` 设为 `SCNet-Max` 即可使用，支持流式输出、思考内容（`reasoning_content`）与用量统计。
- 仅使用 SCNet 免费活动额度，不消耗已购买的 token 包；其他模型仍由百度账号池提供。
- SCNet 登录凭据自动续期：密钥失效时自动重新派生免费活动密钥；额度耗尽时单独标记该账号，不影响百度账号。
- 按平台隔离的故障退避：SCNet 上游异常不会冷却百度账号，反之亦然。
- 控制台账号列表为 SCNet 账号显示「超算」徽章；模型列表仅在已添加 SCNet 账号时出现 `SCNet-Max`。

## 使用说明

- 添加 SCNet 账号可用能接收短信的手机号，或用户名 + 密码。短信验证码会话 10 分钟有效，最多发送 5 次，重发间隔 60 秒；账密登录会话同样 10 分钟有效，最多尝试 5 次。
- `SCNet-Max` 仅支持免费活动额度；请求其他模型时仍走原有百度账号池，行为不变。
- Responses 接口使用 `SCNet-Max` 时需提交完整 `input` 历史，暂不支持 `previous_response_id` 取回；流式工具调用事件暂未逐段下发，非流式最终响应包含完整 `tool_calls`。
- 原有百度账号、扫码/短信加号、积分领取与原生工具续接等功能保持不变。

## 安装与升级

沿用 [一键安装与升级命令](https://github.com/IKUNHEIHIE/kuku2api/blob/main/docs/installation.md) 即可获取 v1.4.0，无需在用户服务器构建前端。升级保留账号、数据库、管理员令牌、API 密钥、端口和系统设置，并在升级前自动备份；已有百度账号不受影响，SCNet 账号需在控制台另行添加。

[v1.4.0 发布包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.4.0) 提供 `kuku2api.tar.gz`、`kuku2api.zip` 和 `SHA256SUMS`。
