# kuku2api v1.1.1

发布日期：2026-10-13。

## 修复与优化

- 积分领取共用后端队列：第一个账号立即处理，每个账号处理完毕后至少等待 15 秒，再处理下一个。手动批量、单账号、立即执行每日任务和定时自动领取均遵守该节奏，失败后也会等待，避免不同领取请求重叠。
- 控制台显示依次领取提示，并减少批量领取与每日任务的重复操作。长批量请求每 10 秒发送 JSON 空白字符保活，最终响应格式保持兼容；前端识别保活开始后的请求级错误。
- 工具模式实时转发正文与思考，不再等整轮结束后输出；可执行工具调用仍须完成参数校验与原生交接后才交付。
- 并行准备独立 ID、图片和控制连接，减少发送前的串行等待；完整系统指令只发送一次，保留完整用户消息、工具调用及结果。
- 修复有效原生工具调用后出现等待事件被误判为失败的问题，以及 Responses 输出索引与最终结果的一致性。
- 在现有系统日志增加工具请求分段计时，便于区分准备、工具发现和上游生成耗时；日志不包含提示词、工具参数、结果正文或凭据。

工具发现及模型思考仍可能耗时，本版本不承诺固定首字延迟。接口行为、长请求错误处理与能力边界见 [API 文档](../api.md)，客户端配置见 [使用说明](../usage.md)。

## 安装与升级

使用 [一键安装/升级](../../README.md#快速安装)，或下载 [v1.1.1 预编译包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.1.1)。提供 `kuku2api.tar.gz`、`kuku2api.zip` 与 `SHA256SUMS`。

Windows、Linux/macOS 安装及升级入口均自动获取最新正式发布包并校验 SHA-256；安装命令无需变更。控制台在 GitHub Actions 构建，用户服务器无需构建或安装前端依赖。需要的 Node.js 运行时由安装器自动检测或下载。

重复安装命令或运行安装目录内的升级脚本即可升级，保留账号、管理员令牌、API 密钥、端口与系统设置。升级前自动备份，不覆盖已有正式版发布资产。

## 验证

本地完整后端回归 427 项、前端接口回归 55 项及正式控制台构建通过。领取节奏使用虚拟时间和模拟账号验证，包含并发单号、手动与自动任务重叠、失败后继续及排队期间账号变更，不批量调用真实账号领奖。

发布流程另在 Linux、Windows 执行后端和安装回归，通过控制台构建、发布内容检查与无构建工具安装验证后，生成并发布预编译安装包。
