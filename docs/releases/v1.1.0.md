# kuku2api v1.1.0

发布日期：2026-10-13。

## 新增与修复

- 支持客户端工具调用：通过库库AI原生 MCP 通道提供真实工具定义，将结构化调用转换为 OpenAI Chat Completions / Responses 事件，并接收客户端执行后的结果。读写文件和命令执行由客户端完成。
- 支持 Chat 和 Responses 的图片输入，包括工具返回的图片、Base64 数据及公开 HTTP/HTTPS 图片地址。图片实际上传并关联上游会话；增加格式、大小、地址与下载期限校验。
- 工具模式重放完整对话及工具历史；Responses 保存的上下文支持 `previous_response_id` 续接，并保持账号隔离。`store:false` 时由客户端重传历史。
- 修复系统指令及历史消息传递，保存结构化调用与用量统计；模型 usage 包含上游多次推理合计，详见 API 文档。
- 保留发送前能力校验，未知工具、非法参数及不支持的附件明确报错；已发送的付费请求不自动换号重发。

## 已验收范围

- GLM Flash 和 DeepSeek Flash：原生工具调用、结果回传及图片输入。
- OpenCode 1.19.0 + GLM Flash：实际读文件、修改文件、运行检查及最终回答。
- Pi 1.2.0 + GLM Flash：Chat 与 Responses 均完成识图、写文件、执行固定检查及最终回答。
- 实际云端 HTTPS 入口：流式工具调用及结果回传正常。

工具输出经缓冲校验后发送。提供商托管工具、grammar 自定义工具及图片之外的二进制附件仍不支持；长期任务压缩、子 Agent 及所有 MCP 插件尚未逐项验收。客户端配置及限制见 [使用说明](../usage.md)、[API 文档](../api.md) 和 [验收记录](../agent-upstream-verification.md)。

## 安装与升级

使用 [一键安装/升级](../../README.md#快速安装)，或下载 [v1.1.0 预编译包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.1.0)。Linux/macOS 与 Windows 安装入口均获取最新正式版并校验 SHA-256；重复安装命令或运行安装目录内的升级脚本即可升级。

前端在 GitHub Actions 构建，用户服务器无需构建或安装前端依赖。升级保留账号、管理员令牌、普通 API 密钥、端口和系统设置；新安装日志默认保留 7 天。本版本没有前端源码变更。

## 验证

后端回归覆盖工具定义、参数与历史校验、Chat / Responses 流式与非流式往返、图片上传和地址校验、取消与超时、账号隔离及存储。发布流程执行 Linux、Windows 回归、控制台构建及无构建工具安装验证，再发布安装包。
