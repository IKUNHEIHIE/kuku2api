# kuku2api v1.2.0

发布日期：2026-10-14。

## 修复与改进

- 改进异常账号切换：发送前的登录失效、临时上游故障及确认未生成的余额拒绝，可尝试其他可用账号。已经生成内容、产生用量或结果不确定的请求不会自动重复提交；后续请求会避开异常账号。
- Agent 的 Responses 续聊可恢复已保存的完整工具历史与结果，在安全条件下切换可用账号；显式指定账号和普通上游会话继续遵守账号归属限制。
- 新增登录凭据定时检测与续期，默认每 6 小时运行，账号之间间隔 15 秒，忙碌账号推迟处理。续期先核验登录与账号身份、保存成功后再启用新 STOKEN，失败保留原凭据。
- 控制台增加续期开关、周期、单号/全部刷新以及最近检测和刷新时间。重新扫码或短信登录已有账号时，更新原账号凭据并保留设置。
- 修复续期等待后错误归属、手动全量刷新被定时任务错误合并及排队期间停用账号仍发送对话的问题；旧账号重新登录时同步补齐已验证身份。
- 后台轮询保留账号弹窗中尚未提交的输入，旧查询响应不会覆盖更新后的账号状态或恢复已删除账号。
- 移除“超过 128 个工具”及“工具定义超过 2 MiB”的额外限制，继续保留请求体和对话内容的大小校验。稳定工具定义的对象键顺序，保留数组顺序及全部参数，减少相同工具定义的序列化差异。

## 使用说明

旧账号未保存 PTOKEN 时，需要重新扫码或短信登录一次以启用实际续期，无需删除账号。BDUSS/PTOKEN 被上游撤销或失效后仍需重新登录。上游未提供精确 Token 到期时间，控制台显示实际检测和刷新记录。

接口及安全换号规则见 [API 文档](../api.md)，日常维护见 [运行维护](../operations.md)。

## 安装与升级

Windows、Linux/macOS 的 [一键安装与升级命令](../installation.md) 自动下载最新正式预编译包，校验 SHA-256 后安装；用户服务器无需构建前端。Node.js 运行时由安装器自动检测或下载。

[v1.2.0 发布包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.2.0) 提供 `kuku2api.tar.gz`、`kuku2api.zip` 和 `SHA256SUMS`。升级保留账号、管理员令牌、API 密钥、端口和系统设置，并在升级前自动备份。
