# kuku2api v1.0.0

发布日期：2026-10-12。首个正式版。

## 主要功能

- OpenAI 兼容的 Chat Completions、Responses、流式输出与思考档位。
- 多账号池、扫码与短信登录、重复账号识别、账号及会话隔离。
- 管理员令牌与模型 API 密钥独立鉴权。
- SQLite 保存账号、设置、对话、日志、token 与积分用量；网页控制台统一管理。
- 手动领取积分，每日自动领取默认关闭。
- 一键安装与升级使用预编译控制台，用户服务器无需构建或安装前端依赖。
- Linux root + systemd 环境自动后台托管、开机启动、异常重启；安装检查成功后显示完成提示并退出。

## 本版调整

- 新安装日志默认保留 **7 天**，前后端默认值一致；启动及每小时清理过期日志。
- 升级保留已有日志保留设置，不把用户保存的 30 天或长期保留强制改为 7 天。
- 修复日志页面源码被忽略规则排除的问题，发布包完整包含 `/logs` 路由，并增加发布回归检查。
- 保留端口选择、系统时区识别中英文、管理员强令牌生成与同源 HTTP/HTTPS 地址识别。

## 安装与升级

下载 [v1.0.0 正式版](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.0.0)，或使用 [一键安装](https://github.com/IKUNHEIHIE/kuku2api#快速安装)。已有安装重复执行安装命令即可升级，保留账号、密钥、端口及设置。

| 文件 | 用途 |
|---|---|
| `kuku2api.tar.gz` | Linux/macOS 预编译控制台与后端源码 |
| `kuku2api.zip` | Windows 预编译控制台与后端源码 |
| `SHA256SUMS` | 安装包 SHA-256 校验值 |

要求 Node.js ≥24.15.0；安装器可下载并校验私有运行时。公开访问时需自行配置防火墙与 HTTPS。

## 升级说明

接口字段与鉴权方式保持兼容；日志默认值变动详见 [API 文档](https://github.com/IKUNHEIHIE/kuku2api/blob/v1.0.0/docs/api.md#系统设置)。对话默认长期保留，累计用量与升级备份不会随日志过期而删除，需按实际磁盘容量管理。

项目原创代码采用 0BSD；前端模板原有 MIT 声明保留在分发包中。上游模型、登录和积分活动的可用性仍取决于库库AI。
