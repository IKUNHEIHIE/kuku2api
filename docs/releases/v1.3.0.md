# kuku2api v1.3.0

发布日期：2026-10-15。

## 修复与改进

- 改进账号冷却：临时故障采用递增退避，成功后恢复；多个账号遭遇相同上游故障时短暂暂停相关请求，避免连续请求放大故障。
- 区分登录失效、积分不足与暂时冷却。暂时没有可用账号时返回可识别的冷却错误及重试时间；已开始生成的任务不会自动重发。
- 精简 Agent 适配提示词，按需发现工具，要求静默完成连接器准备，减少重复规则及过程播报。
- 默认启用原生工具续接，客户端工具结果通过原生回调交回同一上游轮次，减少重复发送历史和重复加载工具。
- 支持 Responses 一层工具命名空间，正确区分不同分组中的同名工具，并保留调用名称、参数和历史。
- 修复上游等待事件早于工具请求到达时的误判，避免合法工具调用被提前中断。
- 将工具执行等待与模型生成超时分开，改善多轮、长任务工具链；中途变更工具、模型或指令时安全切换任务。

## 使用说明

原生工具续接默认开启，每次等待工具结果最多 300 秒，单次生成默认 180 秒，整体任务最多 30 分钟。工具、模型、思考深度或指令变化，以及图片工具结果，会在确认关闭旧任务后携带历史进入新任务；服务重启不恢复正在等待的工具链。需要独立轮次时，可设置 `NATIVE_AGENT_CONTINUATION=0`。详细说明见 [API 文档](https://github.com/IKUNHEIHIE/kuku2api/blob/main/docs/api.md#原生工具续接)。

## 安装与升级

本次保留 v1.3.0 版本号，重新构建并更新安装包。沿用 [一键安装与升级命令](https://github.com/IKUNHEIHIE/kuku2api/blob/main/docs/installation.md) 即可下载更新后的包，无需在用户服务器构建前端。升级保留账号、数据库、管理员令牌、API 密钥、端口和系统设置，并在升级前自动备份。

[v1.3.0 发布包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.3.0) 提供 `kuku2api.tar.gz`、`kuku2api.zip` 和 `SHA256SUMS`。
