# kuku2api v1.3.0

发布日期：2026-10-15。

## 修复与改进

- 改进账号冷却：临时故障采用递增退避，成功后恢复；多个账号遭遇相同上游故障时短暂暂停相关请求，避免连续请求放大故障。
- 区分登录失效、积分不足与暂时冷却。暂时没有可用账号时返回可识别的冷却错误及重试时间；已开始生成的任务不会自动重发。
- 精简 Agent 适配提示词，按需发现工具，要求静默完成连接器准备，减少重复规则及过程播报。
- 新增实验性原生工具续接，连续工具结果可通过原生回调交回同一上游轮次，减少重复发送历史。该功能默认关闭。

## 使用说明

常规安装和升级保持现有工具交接方式。实验功能通过后端环境变量 `NATIVE_AGENT_CONTINUATION=1` 开启，仅适用于短时文本工具链：每次工具等待上限 60 秒，不支持图片工具结果、服务重启恢复或中途更换调用设置。真实上游验收尚未完成，长任务用户应保持关闭。详细限制见 [API 文档](../api.md#实验性原生工具续接)。

## 安装与升级

沿用 [一键安装与升级命令](../installation.md) 即可下载本版，无需在用户服务器构建前端。升级保留账号、数据库、管理员令牌、API 密钥、端口和系统设置，并在升级前自动备份。

[v1.3.0 发布包](https://github.com/IKUNHEIHIE/kuku2api/releases/tag/v1.3.0) 提供 `kuku2api.tar.gz`、`kuku2api.zip` 和 `SHA256SUMS`。
